## Adversarial review and final pass

Three independent reviewers covered lifecycle/cache, experiments/measurement, and UI/delivery. A fourth cross-group review checked changed signatures and statistics consumers. Thirteen findings represented twelve distinct issues (two reviewers independently found the same speculative-position mismatch).

All twelve were reproduced and fixed:

1. Service-based next-request cursors prevent low-budget starvation across multi-tick batches and replenished slots.
2. TP communication prices actual allocated positions; one-position decode performs no draft verification.
3. Unscheduled long prompts no longer inflate an otherwise unchanged decoder's service cost.
4. Recompute counts only previously materialized positions; initial unfinished prefill work is excluded.
5. Nested preemption preserves the earlier lost-context boundary (960 repeated tokens in the regression case).
6. GPU/KV time integrals use the execution interval before terminal state transitions.
7. Reports snapshot mutable arrays rather than retaining live references.
8. Successful completion exactly at 120 seconds is not labelled incomplete.
9. Compare navigation preserves unapplied Runtime controls and local view state.
10. Mobile Runtime controls cannot hide Compare; the workload builder has its own toggle.
11. Cancelled preempted requests show terminal status in History.
12. Prefix blocks show PENDING until admission has produced lookup evidence.

Regression evidence: `src/simulation/review.test.ts` (8 focused cases) and `e2e/review.spec.ts` (3 journeys). Original findings and reproduction scripts are under `artifacts/review/`; `report.html` and `report.md` contain the post-fix outstanding-findings report.
