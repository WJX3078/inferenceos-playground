### v0.1 mental model

- `step`: admit at current time, advance 20 ms, execute per request, update workers/sample, trim terminal history.
- Admission scans FCFS, tests all pools, picks least-loaded feasible pool then cache affinity. Static gates on `admittedAt !== now`.
- Reservation = physical pinned pages + each active request's max-context pages minus block-table length. Shared cached pages counted only once physically.
- Prefill currently 32 * TP_efficiency / sqrt(batch) tokens per tick; decode accumulates compute credit until a synthetic duration. One mutable RNG currently serves burst and speculation.
- Cache keys currently family:index. Only at most 128 tokens/half prompt rounded to full blocks are reusable. Full immutable pages may share; mutable tails cannot.
- Metrics currently TTFT/TPOT over all emitted requests, rolling 1 s throughput. Terminal history capped 160; comparison must not compute lifetime totals from this truncated array.
- UI is rerendered every 40 ms. Compare must have isolated display updates and avoid rerendering hidden Runtime.
